AVATAR
------
Put the real personal photo here as:
assets/avatar.jpg

Recommended format: 1:1, at least 800x800 px. The site will crop it into the square/portrait slot.

HERO BANNER
-----------
The homepage hero uses a remote Unsplash image as the banner and has a gradient fallback underneath it, so the page still looks intentional when the remote image cannot load.

Source: Jouwen Wang / Unsplash
https://unsplash.com/photos/a-full-moon-shining-over-the-ocean-at-night-ZfETVatKa7k
Free to use under the Unsplash License (source page checked 2026-09-20).

The CSS requests an optimized 2400px-wide JPEG from images.unsplash.com, which is enough for a full-width desktop hero without shipping a giant local file.
