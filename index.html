Заказ за три шага

Всё происходит внутри Telegram, сайт нужен только чтобы найти бота.

  1. Откройте ботаНажмите «Открыть бота в Telegram» и отправьте /start.
  2. Пополните кошелёкВведите сумму, оплатите по реквизитам и отправьте чек. Баланс обновится после проверки.
  3. Выберите пакетУкажите игровой ID в формате 123456789 (12345) и подтвердите заказ. ID можно сохранить в кошельке.
