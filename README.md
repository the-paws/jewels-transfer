# Azamatuly — personal site

Статический многостраничный personal/vlog сайт на чистых HTML + CSS + JS.

## Запуск

Открыть `index.html` в браузере. Для локальной разработки удобнее любой статический сервер, например VS Code Live Server.

## Структура

- `index.html` — главная, hero, профиль, навыки, пасхалки, контакты.
- `about.html` — отдельная страница «Обо мне».
- `skills.html` — отдельная страница навыков.
- `contact.html` — отдельная страница контактов.
- `styles.css` — вся визуальная система.
- `script.js` — scroll reveal, 3D-параллакс, меню, copy-to-clipboard и пасхалка.
- `assets/avatar.jpg` — сюда положить реальное фото 1:1.

## Фото

Рекомендуемый аватар: JPEG/WebP 800×800 или больше, соотношение 1:1. Просто положите его по пути `assets/avatar.jpg` — сайт сам начнёт его показывать вместо букв AM.

Hero использует free Unsplash photo by Jouwen Wang:
https://unsplash.com/photos/a-full-moon-shining-over-the-ocean-at-night-ZfETVatKa7k

Источник проверен 20 сентября 2026; страница Unsplash указывает, что фото свободно для использования по Unsplash License.

## Пасхалка

Введите `RIMURU` с клавиатуры на сайте — включится небольшой hidden mode и изменится палитра интерактивной сферы.
Нажатие `/` открывает быстрый навигатор по страницам.
